# Power BI

Aquí se almacenará el archivo `.pbix` y la documentación de conexión a los endpoints `/api/v1/reports/*`.

Endpoints tabulares disponibles:

- `/api/v1/reports/usage`: consumo diario por usuario, servicio y modelo.
- `/api/v1/reports/conversations`: actividad por conversación.
- `/api/v1/reports/summary`: indicadores globales.

Todos requieren un token JWT de administrador.
